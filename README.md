# 🚀 2409 Academy

### Code. Learn. Build. Lead.

**2409 Academy** is a modern learning platform built to help aspiring developers and technology enthusiasts develop practical programming skills, strengthen problem-solving abilities, and prepare for real-world software engineering careers.

Our mission is simple: make quality technical education accessible, practical, and career-focused.

---

## 🌟 About the Platform

2409 Academy brings learning and hands-on development together through structured courses, practical examples, and developer-focused resources.

### 📚 Learning Paths

- ☕ **Java Programming** – From fundamentals to advanced concepts.
- 💻 **Data Structures & Algorithms** – Strengthen problem-solving skills.
- 🗄️ **SQL & Databases** – Learn database design and queries.
- 🏗️ **System Design** – Understand scalable software architecture.
- 🌐 **Web Development** – Build modern web applications.
- 🤖 **AI & Machine Learning** – Explore intelligent technologies.
- ☁️ **Cloud Computing** – Discover modern cloud platforms.

*Some learning paths are under development and will be released progressively.*

---

## ✨ Key Features

- Modern and responsive user interface.
- Structured programming courses.
- Student registration and login.
- Backend authentication using Spring Boot.
- PostgreSQL database integration.
- Admin panel for platform management.
- Practical, developer-focused learning experience.

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd 2409-Academy
```

### 2. Run the frontend

```bash
npm install
npm run dev
```

### 3. Run the backend

Configure your PostgreSQL database and update the backend `application.properties` file.

Then run:

```bash
cd backend
mvn spring-boot:run
```
